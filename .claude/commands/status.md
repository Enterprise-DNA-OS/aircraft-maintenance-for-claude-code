description: Is this aircraft good to fly today? Everything that stops it (overdue items, life limits, directives, defects, unreleased work, bad releases) and what is coming up.
---

1. Run `npm run mx -- status <reg>` (no registration for the whole fleet).
2. Lead with the answer: SERVICEABLE or NOT SERVICEABLE.
3. List each STOP line with the one action that clears it and who owns it (engineer, chief pilot, office).
4. Then the "soon" lines, so the next work pack can be planned.
5. Never say an aircraft is serviceable when the output says it is not. This is a records check: the engineer and the pilot still make the call.
